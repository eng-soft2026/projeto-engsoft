# 20 — Pontos Ainda Não Definidos

As decisões levantadas nas entrevistas iniciais foram resolvidas. Este documento passa a registrar somente decisões futuras não bloqueantes.

## Nenhum ponto crítico pendente

A especificação atual possui definição suficiente para iniciar:

- DER;
- `schema.prisma`;
- estrutura Next.js;
- backlog técnico;
- prototipação;
- implementação incremental.

## Decisões que podem ser refinadas sem alterar o domínio

- identidade visual final e nome comercial da plataforma;
- credenciais/servidor SMTP usados no deploy acadêmico;
- domínio final da aplicação;
- limites operacionais menores que as cotas máximas do Cloudinary, caso o ambiente de demonstração exija;
- ajuste dos pesos da fórmula de relevância após testes com dados seedados;
- detalhes visuais dos templates de e-mail.

Esses itens não devem bloquear o desenvolvimento do modelo de dados ou do núcleo de reservas.
